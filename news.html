Gitus Code Forge

2026.11.2 v0.2.0 Released

  • Two-factor authentication: email, HOTP/TOTP, and recovery codes, with an admin reset.
  • Issue labels.
  • Session metadata and a session list with revocation.
  • Create and delete branches and tags from the web UI.
  • Pull request reviewers; approvals are bound to the current provider commit.
  • Choose the merge method on the pull request page.
  • Configurable repository size limit.
  • SSH key authentication through sshd's AuthorizedKeysCommand.
  • Control namespace creation and default membership for new accounts.
  • Configurable commit message tags, starting with !no-webhook and !no-ci.
  • Proper git submodule handling.
  • New diff view with a changed-file sidebar, plus UI fixes across settings, reviews and issue labels.
  • Bug fixes for fork pages, refs pages, missing pull requests, CSRF-checked forms and diff line numbers.

2026.11.1 v0.1.7

  • MySQL and MariaDB support.
  • Managed update hook that runs the webhook and refreshes fork comparisons.
  • Last-commit listings are memoized inside the repository.
  • Logging levels (info, warn, error, none).
  • Security and performance fixes, including internal error disclosure, receipt binding, rate limits and database indexes.
  • Operation modes renamed to forge, browse-only and host.

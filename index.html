Gitus Code Forge

Gitus is a self-hosted code forge that mainly supports the Git distributed version control system.

Latest Release: v0.2.0 (2026-11-02)
Latest Nightly: v0.2.0+ (2026-11-02)

  • Simple, functional UI;
  • No JavaScript - works all major browsers and a lot of minor ones, including Ladybird, K-Meleon and NetSurf.
  • Proper web installer for easy installation;
  • Read/write access through SSH with per-namespace and/or per-repository user access control;
  • Issue tracking, pull requests and issue labels;
  • Pull request reviewers; every reviewer must approve the current commit;
  • Webhooks for external CI/CD (experimental feature; subject to change)
  • Support for snippets (à la GitHub snippets)
  • Three operation modes for different needs:
    • Browse-only Mode, when you only need a web interface, similar to git-instaweb;
    • Host Mode, for a solo developer or a small team, with users, namespaces and repositories described by specially designated repositories;
    • Forge Mode, the full-featured mode with database-backed users, namespaces and repositories and web-configurable access control.
  • And many tiny things:
    • Branch and tag management from the web UI;
    • Session list with per-session revocation;
    • Two-factor authentication (email, HOTP/TOTP, recovery codes);
    • Configurable repository size limits;
    • SSH key authentication through AuthorizedKeysCommand;
    • Labels for repositories;
    • UI for Git Blame;
    • UI for directly editing files;
    • Co-Authored-By
